agent的使用与见解

日期2026-10-18 作者陈徐 标签AI 工具 · 学习效率

这学期我真正开始把 AI Agent 当成日常工具来用，而不是当成一个「会聊天的搜索框」。 用得最多的是两个：一个是负责办公的 WorkBuddy，一个是专门写代码的 Claude Code。它们解决的是完全不同的问题，下面分别说说我的实际体验。

01日常生活工作的利器——WorkBuddy

WorkBuddy 本质上是一个办公软件，它的主要工作是文件整理、信息调研与远程操控电脑。 目前，我已经使用 WorkBuddy 对我的文件夹中的一些文件进行了整理分类，同时模拟日常办公让它帮我生成了一个 PPT，虽然生成的板式比较基础，但也无疑极大的简化了我的工作量。

同时，我也向它投喂了一些数据让它帮我生成图表，生成的图表效果相比较对话式 AI 例如 DeepSeek 生成的图表有不少的优势。在日常生活中，如果遇到不了解的问题，我也会向 WorkBuddy 提问，它的回复相比较一般的对话型 AI，运用了很多的图表，帮助我加深对提出的问题以及相应答案的理解。

对我来说最明显的区别不是「回答得更好」，而是它会直接动手把事做完—— 文件该移到哪、PPT 该存成什么名字、图表该用哪种形式，它自己判断，我只负责验收。 —— 使用 WorkBuddy 的体感

总之，通过使用 WorkBuddy，我可以提高自己工作中完成各项任务的效率，并使我的日常生活更加的便捷。

02学习编程的强大工具——Claude Code

目前，作为一个大一新生，学习 Python 的编程是一项重要的任务。然而，在普通的编程课上， 老师会让我们从很多基础的代码开始敲起，许多作业以及项目都需要自己全程手动敲代码并试错调试， 这种学习的方式虽然有效，但效率不是特别的高。而 Claude Code 作为一个专门服务于编程的 Agent，可以帮助我更高效地学习编程。

我之前将一个简单但是代码需求较高的任务交给 Claude Code，它在很短的时间内就完成了代码的编写。 对于一些较为复杂、思考了许久都没有思路的问题，我也将其交给 Claude Code，让它帮我生成一个方案—— 从自己写代码到看代码的转变，同样可以使我加深对编程的理解。

如果遇到程序报错检查许久没找到问题的时候，我也会将代码的截图发给它，它可以找到相应的文件， 帮助我找到问题所在并帮我修改。通过使用 Claude Code，我提高了学习编程的效率。

03一点总结

两个工具给我的共同启发是：Agent 的价值不在于替我思考，而在于把我从重复劳动里解放出来， 让我把注意力放在「想清楚要什么」上。

  • 清点性的、流程性的活（整理文件、做图、出提纲）——适合交给 WorkBuddy，省时间最直接。
  • 有明确对错标准的活（写代码、调 bug、查环境问题）——适合交给 Claude Code，反馈快、能自证。
  • 需要自己判断取舍的活（这题该怎么做、这段该不该保留）——还是得自己来，Agent 只能提供选项。

如果完全不动脑地让 Agent 把所有事做完，那学到的东西其实很少；但把它当成一个随叫随到、 不厌其烦的搭档，效率提升是实实在在的。

这一次作业，老师让我们展示 MLP 学习参数的实现与可视化。虽然我是人工智能专业的， 但目前大一阶段，我对人工智能的运行原理还是一知半解的，独立完成这个作业对我来说有比较大的挑战性。 于是，我使用 AI 工具 WorkBuddy 帮助我共同完成了此次作业：网站整体的排版、作业的主题， 以及内容的呈现形式由我负责，而 MLP 的过程呈现则由 WorkBuddy 负责。

在完成了网站的制作后，我也对其中的内容进行了检查与修改，对 MLP 的运行原理进行了追问。 虽然此次作业确实不是由我独立完成，但是借助 Agent 之手，我更加熟悉了网站的搭建流程， 也对 MLP 确实有了更加深入的了解。希望在未来的学习生活中，我也能在使用 Agent 的过程中实现自我提升。
